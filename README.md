# SelectBar

Панель действий над выделенным текстом для macOS. Выделяете текст в любом
приложении — рядом появляется панель с иконками: скопировать, найти,
перевести, произнести, открыть ссылку. Живёт в строке меню, без окна.

Swift, только AppKit и SwiftUI, без зависимостей. Проверено на M3 Pro,
macOS 26.

## Возможности

- Набор кнопок зависит от выделенного: у ссылки — «открыть», у почты —
  «письмо», у текста — поиск, перевод, озвучивание
- Двойной щелчок в пустое поле показывает кнопку вставки
- Перевод через установленное приложение DeepL, а не через браузер
- Свои пункты: открыть ссылку по шаблону или выполнить команду оболочки,
  где `{text}` — выделенный текст
- Настройка размера, темы, стиля подложки и оттенка
- Подсветка клавиатуры мигает на уведомления
- Раскрутка вентиляторов по кнопке

## Устройство

Несколько мест, где очевидное решение не работает.

**Выделение.** Обычного атрибута `AXSelectedText` хватает не везде: в
приложениях с веб-представлениями его нет вовсе, там выделение достаётся
запросом `AXStringForTextMarkerRange`. Если и это не сработало — обход
поддерева сфокусированного элемента, затем его окна.

**Панель не забирает фокус** (`nonactivatingPanel` с переопределённым
`canBecomeKey`): иначе приложение под ней снимет выделение.

**Синтетического ⌘C нет** намеренно, хотя так делают многие: в Finder такое
копирует выделенные файлы. Цена — приложения, не отдающие выделение через
Accessibility, панель не показывают.

**Яркость и подсветка** — приватные `DisplayServices` и `CoreBrightness`,
подгружаются динамически. Публичного API нет, а IOKit на Apple Silicon для
внутреннего дисплея не работает.

**Уведомления** ловятся подпиской на появление окон процесса
`NotificationCenter`.

## Сборка

```bash
./build.sh && open SelectBar.app
```

Или проектом Xcode — он генерируется из `project.yml` командой
`xcodegen generate` и в репозиторий не входит.

Подпись важна не для безопасности: macOS привязывает к ней выданные
разрешения, иначе доступ пришлось бы выдавать после каждой пересборки.

## Разрешения

Обязателен **Универсальный доступ** — без него не читается выделение.
**Мониторинг ввода** нужен только для необязательной реакции на пробел.

В песочнице приложение работать не может, поэтому и в Mac App Store ему
дороги нет.

## Ограничения

Панель работает там, где приложение отдаёт выделение через Accessibility;
живой текст на картинках не поддерживается. Выделение ловится по отпусканию
мыши — с клавиатуры панель не вызывается.
