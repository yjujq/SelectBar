# SelectBar

Панель действий над выделенным текстом для macOS. Выделяете текст в любом
приложении — рядом появляется маленькая панель с иконками: скопировать,
найти, перевести, произнести, открыть ссылку. Живёт в строке меню, без окна
и без иконки в доке.

Написано на Swift, только AppKit и SwiftUI, без сторонних зависимостей.
Собрано и проверено на MacBook Pro M3 Pro, macOS 26.

## Что умеет

**Панель над выделением.** Набор кнопок зависит от того, что выделено:
у ссылки предлагается «открыть», у адреса почты — «письмо», у обычного
текста — поиск, перевод и озвучивание. Бессмысленные сочетания не
показываются: ссылку не предложат перевести, а имя файла вроде `readme.md`
не примут за домен.

**Вставка в пустых полях.** Двойной щелчок в пустое поле ввода показывает
кнопку вставки с подсказкой о содержимом буфера. Одиночный щелчок — это
просто установка курсора, и панель на него не лезет.

**Перевод через установленный DeepL.** Если приложение DeepL есть в системе,
перевод открывается в нём, а не в браузере. Иначе — запасной путь на сайт,
с автоматическим выбором направления: кириллица переводится на английский,
остальное на русский.

**Свои пункты.** В настройках можно добавить действие двух видов: открыть
ссылку по шаблону или выполнить команду оболочки. В шаблоне `{text}`
заменяется выделенным текстом, а для команды он же доступен в переменной
`SB_TEXT`.

**Внешний вид.** Размер, стиль подложки (сплошная заливка, стекло macOS 26
или размытие), светлая или тёмная тема, оттенок.

**Подсветка клавиатуры.** Мигает при появлении уведомления или по кнопке
в меню. Управляется напрямую через приватный `CoreBrightness`.

**Раскрутка вентиляторов** по кнопке — через отдельную программу с
повышением прав, потому что запись в SMC разрешена только root.

## Как это устроено

Несколько мест, где очевидное решение не работает.

**Выделение читается через Accessibility**, но обычного атрибута
`AXSelectedText` хватает не везде. В приложениях с веб-представлениями —
Почта, Safari, справка — этого атрибута нет вовсе: выделение публикуется
диапазоном текстовых маркеров и достаётся параметризованным запросом
`AXStringForTextMarkerRange`. Если и это не сработало, программа обходит
поддерево сфокусированного элемента, а затем его окна: у панелей вроде
быстрого просмотра приложение считает главным совсем другое окно.

**Панель не забирает фокус.** `NSPanel` со стилем `nonactivatingPanel` и
переопределённым `canBecomeKey`: обычное окно отобрало бы фокус, приложение
под ним сняло бы выделение, и кнопки показывались бы для текста, которого
уже нет.

**Синтетического ⌘C нет.** Многие подобные программы копируют выделение
нажатием клавиш, когда Accessibility молчит. Здесь от этого отказались:
в Finder такое копирует выделенные файлы. Цена — приложения, не отдающие
выделение, панель не показывают.

**Яркость экрана и подсветка клавиатуры** идут через приватные фреймворки
`DisplayServices` и `CoreBrightness` — публичного API для них нет, а путь
через IOKit на Apple Silicon для внутреннего дисплея не работает. Оба
фреймворка подгружаются динамически, так что сборка ни с чем закрытым
не линкуется.

**Уведомления** ловятся подпиской через Accessibility на появление окон
процесса `NotificationCenter` — так срабатывает на баннер от любого
приложения и не нужен доступ к базе уведомлений.

## Сборка

Скриптом, без Xcode:

```bash
./build.sh
open SelectBar.app
```

Либо проектом Xcode — он генерируется из `project.yml`:

```bash
xcodegen generate
open SelectBar.xcodeproj
```

Проект в репозиторий не входит намеренно: он полностью описывается
`project.yml`. После добавления файлов в `Sources` нужно выполнить
`xcodegen generate` заново.

Скрипт подписывает приложение первым найденным сертификатом разработчика.
Подпись здесь не про безопасность, а про разрешения: macOS привязывает
выданный доступ к подписи, и без неё его пришлось бы выдавать после каждой
пересборки.

## Разрешения

**Универсальный доступ** обязателен — без него не читается выделение.
Приложение попросит его при первом запуске.

**Мониторинг ввода** нужен только для необязательной реакции на пробел.

Приложение не может работать в песочнице: Accessibility с ней несовместим.
Поэтому и в Mac App Store такому приложению дороги нет — только прямая
раздача с подписью Developer ID.

## Ограничения

Панель появляется только там, где приложение отдаёт выделение через
Accessibility. Живой текст на картинках и часть нестандартных виджетов
не поддерживаются.

Выделение ловится по отпусканию мыши; выделение с клавиатуры панель
не вызывает.

## Иконка

Рисуется кодом, а не в редакторе: программа в `Tools` генерирует все десять
размеров от 16 до 1024 пикселей через Core Graphics. Правки вносятся в одном
месте и расходятся по всем размерам.

```bash
swiftc -O -o Tools/makeicon Tools/main.swift -framework AppKit -framework ImageIO
./Tools/makeicon AppIcon.iconset
```
